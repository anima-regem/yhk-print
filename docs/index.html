Print through your Mac

Firefox and other browsers without Web Bluetooth can send jobs through the Mac relay.

On your Mac: Run ./yhk web --no-open, then open the local print app in this browser.

On your phone: Run ./yhk web --share --no-open on your Mac. Connect both devices to the same Wi-Fi and open the address shown in the Mac terminal.

Connection and installation help

Android: Open this page in Chrome, then tap Connect printer. Use Chrome’s Install app option to add it to your home screen.

iPhone: Open the GitHub Pages URL in Bluefy for direct Bluetooth.

Firefox and Safari: Use the Mac relay on your computer or phone.

Keep the printer on and nearby. Disconnect it from other printing apps before connecting here.

Print jobs go directly to the printer or through your Mac. Source on GitHub
